## Goal

`build` yeteneğini NestJS backend'e **async job worker** olarak kazandırmak: mevcut senkron/blocking `mcp/ops.mjs build()` (`spawnSync astro build`) yerine, job kuyruğu (queue) + tek serial worker + job status takibi + enqueue/poll HTTP API. Strangler adımı: backend yeteneği kazanır, MCP bridge şimdilik kalır.

## Architecture

Clean architecture (ports/adapters), `sites` slice pattern'i birebir: thin controller → use-case classes → port interfaces → infrastructure adapters. İki port iki seam'dir: `BuildJobRepository` (state kalıcılığı) ve `BuildRunner` (build çalıştırma). `BuildWorker` yalnız bu iki porta bağımlı orchestration'dır; Redis/DB/real-build swap'leri bu seam'lerden ucuz yapılır.

Job state **file-backed**: `.astropress/builds.json` (mevcut `tasks.json`/`audit.json` runtime-state convention'ı, `store.mjs` parity). Config değil runtime state → `.astropress/` ignore'lu kalır. Tek process, **serial worker** (concurrency 1) → `dist/` üzerinde astro build yarışı imkânsız.

## Domain Model

### BuildJob entity (`builds/domain/build-job.ts`)

Value object, immutable; transition method'ları yeni instance döner. Read-time revalidation `BuildJob.create` ile (tek doğrulama noktası — `Site.create` felsefesi).

```typescript
export type BuildStatus = 'queued' | 'running' | 'succeeded' | 'failed';

// Domain value object: build çalıştırmanın sonucu (domain katmanı — application buna bağımlı, tersi değil).
export interface BuildResult {
  ok: boolean;
  exitCode: number;     // spawn fail/timeout: -1
  logTail: string;      // stdout+stderr son ~8 satır
  error?: string;       // spawn fail/timeout mesajı
}

export interface BuildJobProps {
  id: string;
  status: BuildStatus;
  createdAt: string;          // ISO 8601
  startedAt?: string;         // ISO 8601 (running/terminal)
  finishedAt?: string;        // ISO 8601 (terminal)
  exitCode?: number;          // terminal
  logTail?: string;           // terminal (son ~8 satır)
  error?: string;             // failed
}

export class BuildJob {
  static create(props: BuildJobProps): BuildJob;        // validate + reconstruct
  static newQueued(id: string, now: string): BuildJob;  // status queued, createdAt=now
  markRunning(now: string): BuildJob;                   // queued → running, startedAt=now
  markSucceeded(result: BuildResult, now: string): BuildJob; // running → succeeded, finishedAt/exitCode/logTail
  markFailed(error: string, now: string, exitCode?: number, logTail?: string): BuildJob; // running → failed
  toProps(): BuildJobProps;
  // getters: id, status, createdAt, startedAt, finishedAt, exitCode, logTail, error
}
```

**Validation kuralları (`create`):**
- `id`: non-empty string → ihlal `BuildValidationError`.
- `status`: 4 enum değerinden biri → ihlal `BuildValidationError`.
- `createdAt`: geçerli ISO date string (`Date.parse` NaN değil) → ihlal `BuildValidationError`.
- `running` ise `startedAt` zorunlu; terminal (`succeeded`/`failed`) ise `finishedAt` zorunlu → ihlal `BuildValidationError`.

**Transition kuralları:**
- `markRunning` yalnız `queued`'den çağrılır; aksi halde `BuildValidationError`.
- `markSucceeded`/`markFailed` yalnız `running`'den çağrılır; aksi halde `BuildValidationError`.
- Terminal job'dan transition YOK (immutable, yeniden create gerekir).

## Application Layer

### Ports (`builds/application/ports.ts`)

```typescript
import { BuildJob, BuildResult } from '../domain/build-job'; // BuildResult domain'de tanımlı

export const BUILD_JOB_REPOSITORY = Symbol('BUILD_JOB_REPOSITORY');
export const BUILD_RUNNER = Symbol('BUILD_RUNNER');

export interface BuildRunner {
  run(): Promise<BuildResult>;
}

export interface BuildJobRepository {
  save(job: BuildJob): Promise<void>;
  findById(id: string): Promise<BuildJob | null>;
  findAll(): Promise<BuildJob[]>;
}
```

### Use-cases

- **`EnqueueBuild`** (`enqueue-build.ts`): constructor `@Inject(BUILD_JOB_REPOSITORY) repo: BuildJobRepository` + `worker: BuildWorker` (class token → constructor type injection, `@Inject` DEĞİL). `execute(): Promise<BuildJob>` → id üret (`build-<seq>-<ts36>`; module-level monotonic `let seq = 0`, `++seq` + `Date.now().toString(36)` — concurrent POST'larda collision yok), `BuildJob.newQueued(id, now)`, `repo.save`, `worker.kick()` (fire-and-forget drain tetikle), job döner.
- **`GetBuildJob`** (`get-build-job.ts`): `execute(id: string): Promise<BuildJob>` → `repo.findById`; null ise `BuildJobNotFoundError(id)`.
- **`ListBuildJobs`** (`list-build-jobs.ts`): `execute(): Promise<BuildJob[]>` → `repo.findAll`, `createdAt` DESC sıralı (yeniden eskiye).

### BuildWorker (`builds/application/build-worker.ts`)

`@Injectable()`, `OnModuleInit`. `@Inject(BUILD_JOB_REPOSITORY)` repo + `@Inject(BUILD_RUNNER)` runner.

- **`kick(): void`** — drain zaten koşmuyorsa `void this.drain()` başlatır (EDD-lite direct notify; polling YOK).
- **`drain(): Promise<void>`** — public async (testler await edebilir). Single-flight guard: aktif drain varsa aynı promise'ı döner (çift işleme YOK). Serial loop:
  1. `findAll` → `queued` filtrele, `createdAt` ASC sırala (FIFO).
  2. Queued yoksa bitir.
  3. İlk job'ı `markRunning(now)` → `repo.save`.
  4. `result = await runner.run()`.
  5. `result.ok` ise `markSucceeded(result, now)`; değilse `markFailed(result.error ?? 'build failed', now, result.exitCode, result.logTail)` → `repo.save`.
  6. Döngü başına dön (tek tek await → concurrency 1).
- **`onModuleInit()` → `recover(): Promise<void>`** — boot'ta `findAll`; `running` job'lar (önceki crash) `markFailed('interrupted', now)` → `repo.save`. Empty/no-running ise **no-op (write YOK)** → sites e2e testleri gerçek `.astropress`'e dokunmaz.

**Concurrency guard:** aktif drain promise'ı (`drainPromise: Promise<void> | null`); `kick`/`drain` bunu kontrol eder. Serial await loop zaten tek build garanti eder; guard eşzamanlı drain başlatmayı önler.

### AstroBuildRunner (`builds/infrastructure/astro-build-runner.ts`)

`@Injectable()`, `@Inject(ASTROPRESS_ROOT)` root: string.


- `run(): Promise<BuildResult>` — `child_process.spawn(process.execPath, [path.join(root,'node_modules','astro','astro.js'), 'build'], { cwd: root })`. **Async** (`spawnSync` DEĞİL).
- stdout+stderr toplanır; timeout **180000ms** (ops.mjs parity) → `child.kill()`, `ok:false, exitCode:-1, error:'timeout'`.
- `close` event: `ok = code===0`, `exitCode = code ?? -1`, `logTail` = birleşik output son 8 satır.
- `error` event (spawn fail): `ok:false, exitCode:-1, error:message, logTail`.
- Resolve daima `BuildResult` (throw ETMEZ — worker failure'ı job'a yazar).

## Scalability Phases

- **Faz 1 (P2.4, bu slice):** in-process serial worker, file-backed jobs, tek instance, Redis yok.
- **Faz 2:** BullMQ + Redis queue (multi-worker, retry, rate-limit). `BuildRunner` aynı kalır; queue adapter değişir. Job retention policy.
- **Faz 3:** DB adapter persistence (sites storage pattern reuse), EventStore + resumability, tam event-driven (EDD). `BuildJobRepository` DB adapter'ına taşınır.

Port'lar (`BuildRunner`, `BuildJobRepository`) bu swap'leri ucuz tutar.
